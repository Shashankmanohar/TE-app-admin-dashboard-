# Team Excellent Admin Dashboard

Admin panel for the Team Excellent Career Institute Platform.

## Technology Stack
- React
- Vite
- TailwindCSS
- Lucide React (Icons)
- Recharts (Charts)

## Getting Started

### Prerequisites
- Node.js installed locally

### Installation
1. Clone the repository or navigate to this folder.
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application
- Development mode (starts the local dev server):
  ```bash
  npm run dev
  ```
- Build the application for production:
  ```bash
  npm run build
  ```
- Preview the production build:
  ```bash
  npm run preview
  ```
